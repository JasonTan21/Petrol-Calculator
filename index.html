Current price source

Prices sync from Malaysia's official OpenDOSM fuel price API when available. The "Refresh prices" button retrieves the latest published RON95, BUDI95 and SKPS rates. If unavailable, the last successfully fetched official rates are used. With no saved rates, the application displays its older August 2026 fallback with a clear warning. Previously saved payment records without historical rate snapshots may be recalculated using the displayed rates.
